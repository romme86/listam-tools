## What the research changed

Autobase **7.28.2**, Hyperswarm **4.17.1**, Hypercore **11.36.1** and Corestore
**7.12.5** are aligned across the four active runtime graphs. HyperDHT **6.34.0**,
udx-native **1.21.1** and blind-relay **1.6.1** were retained. Relay selection
starts randomly and cycles through configured candidates on fallback attempts.
Blind-storage and owner-control paths now receive the same relay configuration.

Authenticated list-data mirroring now persists both sides of the subscription:
participants publish revisioned manifests containing public base/system/view/
writer core keys; helpers validate the authenticated device scope, reject
stale/conflicting revisions, and persist before acknowledging. Historical
writer keys are retained in the manifest union. Reconciliation, retries,
withdrawal and restart restoration are bounded. Helpers receive no list
plaintext or encryption keys. Withdrawal stops active downloads while keeping
already stored ciphertext.

The headless archive vendors the exact shared packages, so it installs without
unpublished npm versions or sibling workspace paths. Extract it, enter
`package/`, then run `npm install --omit=dev`. Installing the outer tarball from
another directory is not the supported path because the vendored references
are relative. The `--registry` distribution mode remains available for a later
npm release. No npm package was published in this rollout.
